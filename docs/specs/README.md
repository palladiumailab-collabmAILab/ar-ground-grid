# Project specifications

このディレクトリを、現在有効な製品・システム要件の正本とする。

## Current specifications

- [Product](product.md) — 目的、対象ユーザー、価値、スコープ、成功条件
- [Requirements](requirements.md) — MVP、機能要件、非機能要件、受入条件

## Rules

- 観測可能な挙動、データ契約、外部インターフェースを変更する前に、関連仕様を読む。
- 現在有効な要件だけをここに置く。廃止済みの判断や履歴は `docs/decisions.md` 等へ分離する。
- アーキテクチャ文書は「どう実現するか」を扱い、このディレクトリの要件と競合する正本を作らない。
- Issue は作業単位であり、現在仕様の代替にはしない。
- 実装と仕様が矛盾する場合は、どちらを正とするか解決するまで黙って片方に寄せない。
- 同じ規範的要件を複数箇所へ重複させない。
