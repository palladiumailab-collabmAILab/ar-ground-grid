# Product specification

## Problem

- 家具配置、DIY、撮影、現場確認などで、床・地面上の実寸スケールをその場で把握したい。
- メジャーや墨出しは確実だが、広い範囲の概略配置や構図確認では手間がかかる。
- カメラ越しに実寸グリッドを重畳できれば、位置・大きさ・間隔を直感的に確認できる。

## User

- Primary user: 家具配置、DIY、撮影、現場確認で概略寸法を視覚化したいAndroidユーザー
- 利用場面: 室内床、舗装面など、ARで水平面を追跡できる場所
- 利用頻度: 必要時に短時間起動して配置・寸法感を確認

## Value proposition

- カメラ越しの水平面に、実世界のメートル単位と対応するグリッドを固定表示する。
- 10 cm単位の小グリッドと1 m単位の主線により、広さ・位置・間隔を視覚的に把握できる。
- 初期MVPでは計測器の代替ではなく、実寸スケールのAR可視化に集中する。

## Success criteria

- [ ] Android端末で水平面を検出し、ユーザーがタップした位置へグリッドを固定できる。
- [ ] グリッド生成ロジック上、隣接する小線の間隔が0.1 m、主線間隔が1.0 mである。
- [ ] 4 m × 4 mのグリッドを表示し、ユーザー操作で再配置できる。
- [ ] AR追跡が不十分な場合に、その状態をユーザーへ表示できる。
- [ ] 実機で1 m基準長に対する実測誤差を記録し、計測用途をうたう前に精度特性を確認できる。

## Non-goals

- 初期MVPではiOS版を実装しない。
- 法定計量、施工検査など、保証された測量・計測器用途を対象にしない。
- 家具3Dモデル配置、部屋スキャン、クラウド同期、アカウント機能は実装しない。
- 初期MVPでは手動キャリブレーションを実装しない。

## Open questions

- [ ] 実機評価後、実用上許容する距離誤差の閾値を決める。
- [ ] 4 m四方より広いグリッドが必要かを利用評価で確認する。
- [ ] iOS実装時にSceneView/RealityKitを採用するか、ARKitを直接利用するかを再評価する。
